# Flame in Freefall

NASA Space Apps 2026 — fire-safety insights from NASA microgravity combustion data.

```
flame-in-freefall/
├── backend/
│   ├── main.py        # API endpoints (FastAPI)
│   ├── schemas.py     # JSON shapes = contract with frontend
│   ├── data.py        # loads CSVs + analysis.json
│   ├── matching.py    # finds closest experiments (no AI)
│   ├── ai.py          # all Gemini calls + prompts
│   └── analyze.py     # one-time AI summaries -> data/analysis.json
├── data/
│   ├── experiments.csv   # one row per test (data team)
│   ├── materials.csv     # allowed material names + display names
│   └── analysis.json     # generated by analyze.py
├── frontend/          # frontend team's code
├── API.md             # endpoint + JSON reference for the frontend
└── requirements.txt
```

## Setup (once)
```
pip install -r requirements.txt
```
Create `.env` in the repo root (it's in .gitignore — never commit it):
```
GEMINI_API_KEY=your_key_here
GEMINI_MODEL=gemini-2.5-flash
```

## Run
All commands from the repo root:
```
python -m backend.analyze          # after new verified rows are added
uvicorn backend.main:app --reload  # start API at http://localhost:8000
```
Open http://localhost:8000/docs to test every endpoint in the browser.

## Data rules
- Only rows with `verified = yes` are served by the API.
- `material` must exactly match a name in `materials.csv`
  (details like thickness go in `name`). Add new materials there first.
- Numbers come from the source documents, never from the AI.

| material | plain English | type | priority |
|---|---|---|---|
| SIBAL fabric | cotton/fiberglass cloth | solid | 1 |
| cotton fabric | cotton jersey | solid | 1 |
| PMMA | acrylic plastic | solid | 1 |
| Nomex | fire-resistant fabric | solid | 1 |
| silicone | silicone sheet | solid | 1 |
| Ultem | high-performance plastic | solid | 1 |
| wax-fiberglass | wax-soaked fiberglass | solid | 1 |
| heptane / methanol / heptane-isooctane | liquid fuel droplets | liquid | 2 |
| ethylene / methane | gaseous fuels (ACME BRE) | gas | 3 |

## Updating data while the server runs
Drop in the new `experiments.csv`, run `python -m backend.analyze`, then
`curl -X POST http://localhost:8000/admin/reload`.

## Deploy (Google Cloud Run, uses the $300 credit)
```
gcloud run deploy flame-api --source . --region us-west1 \
  --set-env-vars GEMINI_API_KEY=your_key,FRONTEND_ORIGIN=https://your-frontend-url
```
Cloud Run needs a start command; add a `Procfile` containing:
`web: uvicorn backend.main:app --host 0.0.0.0 --port $PORT`


## Numeric stowage planner
`POST /planner/assess` scores cruise-only, lunar, or Mars ship inventories with
verified experiment material screens and explicitly labeled prototype layout weights.
It runs without Gemini. Try `data/planner_example.json` in `/docs`; see `API.md`
for formulas, unknown-score ranges, equipment fields, and the frontend contract.
Placement phases are now `cruise` and `surface`; `pre_launch` is rejected.
Run backend regression tests with:
```
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```
